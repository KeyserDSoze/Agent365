# 01 — Foundations: Microsoft Agent 365

## Obiettivo
Costruire un mental model comune prima di entrare nei singoli prodotti.

## Definizione operativa
Microsoft Agent 365 è il control plane Microsoft per **osservare, governare e proteggere** agenti AI su scala enterprise, anche quando provengono da runtime e piattaforme differenti.

È commercialmente GA per il segmento Commercial dal **1 maggio 2026**. La documentazione corrente indica Microsoft 365 E5 come prerequisito ottimale; Agent 365 è inoltre incluso in Microsoft 365 E7.

## Perché esiste
L'adozione degli agenti introduce agent sprawl, owner mancanti, identità non governate, over-privilege, tool misuse, data exposure, telemetry frammentata e runtime eterogenei.

Agent 365 non sostituisce i prodotti esistenti: li estende verso il mondo agentico.

## Cinque verbi
1. **Observe** — sapere quali agenti esistono e cosa fanno.
2. **Govern** — ownership, lifecycle, approval, policy.
3. **Secure** — identity, least privilege, detection, response.
4. **Extend** — custom agents, connected platforms, MCP.
5. **Operate** — runbook, KPI, RACI, assessment e POC.

## Interactive vs autonomous
- **Interactive / on-behalf-of:** opera nel contesto di un utente.
- **Autonomous:** usa una propria identità e autorizzazione.

## Output di studio
Disegnare runtime, control plane, identità, dati, tool, telemetry, owner e operating process su un'unica pagina.

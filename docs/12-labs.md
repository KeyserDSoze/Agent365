# 12 — Hands-on Labs

> Usare tenant/lab adeguati. Non fare prove invasive in produzione.

## LAB 01 — Tenant Readiness
Licensing, ruoli, accessi, Agent Overview, gap list.  
**DoD:** checklist compilata + decision log.

## LAB 02 — Registry & Ownership
Inventory, piattaforme, owner mancanti, risk tier.  
**Output:** agent-inventory.csv.

## LAB 03 — Agent ID & Access
Interactive/autonomous, blueprint, sponsor, scope, CA/revocation.  
**Output:** Identity Design Sheet.

## LAB 04 — Defender Hunting
Verifica schema, inventory query, governance gap, tools/MCP, findings.  
**Output:** KQL pack + findings.

## LAB 05 — Purview
Data source, classificazione, operation, policy, evidence.  
**Output:** Data Interaction Matrix.

## LAB 06 — Tool & MCP
Catalogo, read/write, auth, reversibility, risk, mitigation.  
**Output:** Tool Risk Register.

## LAB 07 — Custom Agent
SDK/CLI prereq, identity, telemetry, CI/CD, validation.  
**Output:** onboarding runbook.

## LAB 08 — Local Golden Agent
Foundry Local, inference diretta, Agent Framework API e sessione multi-turn.  
**Output:** report JSON del local lab runner + log runtime.

## LAB 09 — Operational Hardening
Health/readiness, access key opzionale, rate limit, input/session guardrail e diagnostics.  
**Output:** hardening decision sheet + evidenza test HTTP.

## LAB 10 — Tool Governance Runtime
Registry, risk tier, block/unblock, approval one-shot e audit bounded.  
**Output:** tool policy evidence + audit di allow/deny.

## LAB 11 — Run Evidence & Correlation
Run ID, trace ID, evidence privacy-safe, correlation tool audit e summary operativo.  
**Output:** evidence snapshot + correlation proof.

## LAB 12 — Operations Dashboard
Evidence export, KPI, filtri, run drill-down e tool decision correlation.  
**Output:** operations export JSON + dashboard walkthrough.

## LAB 13 — Governed MCP Server
Stdio, tool discovery, risk metadata, block policy, operator approval e audit metadata-only.  
**Output:** MCP manifest + handshake/invocation evidence.

## LAB 14 — Reliability & Incident Operations
Soglie, finding, error taxonomy, incident snapshot e recovery gate.  
**Output:** reliability assessment + incident runbook compilato.

## CAPSTONE
Current-state assessment, baseline, architecture, risk, identity, security/data control, operating model, POC charter, 30/60/90, demo 20 minuti.

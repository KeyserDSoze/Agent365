# 10 — Operating Model

## Minimum RACI

| Activity | M365/Platform | Identity | Security | Data/Compliance | App Owner |
|---|---|---|---|---|---|
| Inventory | A/R | C | C | C | I |
| Identity design | C | A/R | C | I | C |
| Security policy | C | C | A/R | C | I |
| Data controls | C | I | C | A/R | C |
| Tool approval | A | C | C | C | R |
| Incident | C | C | A/R | C | R |
| Retirement | A/R | C | C | C | R |

## Cadence
Weekly governance-gap review; monthly inventory/owner review; high-risk tool review; incident review; quarterly access review; stale-agent cleanup.

## KPIs
Owner coverage, classification coverage, documented identity, high-risk review coverage, remediation time, stale agents, unapproved tools, agent incidents, telemetry coverage and access-review completion.

## Required assets
Inventory, Lifecycle Policy, Identity Sheet, Tool Risk Register, Data Matrix, Incident Playbook, Monthly Report and 30/60/90 Roadmap.

# 12 — Hands-on Labs

> Use a suitable lab tenant. Do not run invasive tests in production.

## LAB 01 — Tenant Readiness
Licensing, roles, access, Agent Overview, gap list.  
**DoD:** completed checklist + decision log.

## LAB 02 — Registry & Ownership
Inventory, platforms, missing owners, risk tiers.  
**Output:** agent-inventory.csv.

## LAB 03 — Agent ID & Access
Interactive/autonomous, blueprint, sponsor, scope, CA/revocation.  
**Output:** Identity Design Sheet.

## LAB 04 — Defender Hunting
Validate schema, inventory query, governance gaps, tools/MCP, findings.  
**Output:** KQL pack + findings.

## LAB 05 — Purview
Data sources, classification, operations, policy and evidence.  
**Output:** Data Interaction Matrix.

## LAB 06 — Tool & MCP
Catalog, read/write, auth, reversibility, risk and mitigations.  
**Output:** Tool Risk Register.

## LAB 07 — Custom Agent
SDK/CLI prerequisites, identity, telemetry, CI/CD and validation.  
**Output:** onboarding runbook.

## LAB 08 — Local Golden Agent
Foundry Local, direct inference, Agent Framework API and a multi-turn session.  
**Output:** local lab runner JSON report + runtime logs.

## LAB 09 — Operational Hardening
Health/readiness, optional access key, rate limits, input/session guardrails and diagnostics.  
**Output:** hardening decision sheet + HTTP test evidence.

## CAPSTONE
Current-state assessment, baseline, architecture, risk, identity, security/data controls, operating model, POC charter, 30/60/90 and a 20-minute demo.

# 11 — Training Plan

## Goal
Take a **Senior + Junior** pair from zero to customer-ready in **45–55 hours across 3 weeks**.

## Model
**Study → Lab → Artifact → Review → Teach-back.**

## Week 1
1. Mental model → architecture map
2. Licensing/roles/readiness → checklist
3. Registry/inventory → baseline
4. Entra Agent ID → Identity Design Sheet
5. Lifecycle/governance → runbook

## Week 2
6. Conditional Access → policy matrix
7. Defender/AgentsInfo → KQL pack
8. Threat scenarios → incident playbook
9. Purview → Data Interaction Matrix
10. Tool/MCP → Tool Risk Register

## Week 3
11. Observability → Telemetry Matrix
12. SDK/CLI → onboarding checklist
13. Connected platforms → integration architecture
14. Operating model/discovery → RACI + discovery pack
15. Capstone → assessment, architecture, controls, demo, POC and 30/60/90 roadmap

## Senior focus
Architecture, identity/security decisions, risk, workshops, customer narrative and POC design.

## Junior focus
Inventory, evidence, query execution, documentation, checklists, repeatable runbooks and troubleshooting.

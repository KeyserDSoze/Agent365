# 01 — Foundations: Microsoft Agent 365

## Goal
Build a shared mental model before diving into individual products.

## Working definition
Microsoft Agent 365 is Microsoft's enterprise control plane to **observe, govern and secure** AI agents across heterogeneous runtimes and platforms.

It became commercially generally available for the Commercial segment on **May 1, 2026**. Current Microsoft guidance positions Microsoft 365 E5 as the preferred prerequisite, while Agent 365 is also included in Microsoft 365 E7.

## Why it exists
Agent adoption creates agent sprawl, missing ownership, unmanaged identities, excessive privilege, unsafe tool use, data exposure, fragmented telemetry and heterogeneous runtimes.

Agent 365 does not replace existing Microsoft products. It extends them into agentic operations.

## Five verbs
1. **Observe** — know which agents exist and what they do.
2. **Govern** — ownership, lifecycle, approvals and policy.
3. **Secure** — identity, least privilege, detection and response.
4. **Extend** — custom agents, connected platforms and MCP.
5. **Operate** — runbooks, KPIs, RACI, assessments and POCs.

## Interactive vs autonomous
- **Interactive / on-behalf-of:** operates in a user context.
- **Autonomous:** uses its own identity and authorization model.

# 13 — Customer Delivery

## Discovery
### Business
Use case, criticità, autonomia accettabile.

### Inventory
Piattaforme, numero agenti, owner, ambienti, shadow agents.

### Identity
Interactive/autonomous, resource, permission, credential, revocation.

### Data
Source, classification, regulated data, DLP, residency/retention.

### Tools
Tool/MCP, read/write, reversibility, third party, secrets.

### Security
SOC, Defender, detection, incident owner, evidence.

## POC 2–4 settimane
1. Baseline: inventory + gap.
2. Controls: identity/governance/Defender/Purview.
3. Integration: tools/MCP/observability/custom agent.
4. Operate: runbook/dashboard/review/roadmap.

## Exit criteria
Inventory affidabile, ownership, un flow end-to-end governato, identity verificata, security/data evidence, incident path e backlog prioritizzato.

## 30/60/90
- 30: visibility e ownership.
- 60: identity/security/data baseline.
- 90: operating model, automation, scale-out, KPI.

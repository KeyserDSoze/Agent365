# 10 — Operating Model

## RACI minimo

| Attività | M365/Platform | Identity | Security | Data/Compliance | App Owner |
|---|---|---|---|---|---|
| Inventory | A/R | C | C | C | I |
| Identity design | C | A/R | C | I | C |
| Security policy | C | C | A/R | C | I |
| Data controls | C | I | C | A/R | C |
| Tool approval | A | C | C | C | R |
| Incident | C | C | A/R | C | R |
| Retirement | A/R | C | C | C | R |

## Cerimonie
Weekly governance-gap review; monthly inventory/owner review; high-risk tool review; incident review; quarterly access review; stale-agent cleanup.

## KPI
% owner, % classified, % identity documented, % high-risk reviewed, remediation time, stale agents, unapproved tools, incidents, telemetry coverage, access-review completion.

## Incident ownership
Definire chi sospende agente, revoca accesso, investiga, conserva evidence, comunica e autorizza recovery.

## Asset
Inventory, Lifecycle Policy, Identity Sheet, Tool Risk Register, Data Matrix, Incident Playbook, Monthly Report, 30/60/90 Roadmap.

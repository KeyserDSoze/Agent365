# Microsoft Agent 365 Knowledge Hub

Bilingual (Italian / English) technical knowledge base and showcase for Microsoft Agent 365.

The repository contains:
- `src/` — React + Vite application published with GitHub Pages
- `docs/` — formal technical documentation, study material and implementation guidance
- `examples/` — practical examples, KQL, policies, checklists and lab assets
- `.github/workflows/` — GitHub Pages deployment pipeline

> This is an independent technical knowledge project. Microsoft product names and documentation links are referenced for educational and implementation purposes.

The content is organized around Observe, Govern, Secure, Extend and Operate, covering Microsoft 365 admin center, Entra Agent ID, Defender XDR, Purview, MCP/tool governance, Agent 365 SDK/CLI, observability and customer delivery.
